### Blockchain-Based Identity & Asset Platform | *Web3 Developer*
**Tech Stack:** Solidity, Express.js, React, Hardhat/Foundry, IPFS, Web3.js

* Engineered a decentralized identity and access management platform utilizing smart contracts to enforce Role-Based Access Control (RBAC) and prevent single points of failure.
* Tokenized physical corporate assets as structurally typed NFTs, assigning them directly to employee DIDs to guarantee tamper-proof ownership and an immutable audit trail.
* Designed a custom QR-code provisioning system that links physical hardware (laptops, badges) to their respective on-chain NFT, allowing instant verification via a React-based web interface.
* Built a secure backend orchestrator in Express.js to listen for on-chain role assignment events and trigger automated external API actions for frictionless employee onboarding.
